SHODY DATA HUB — starter website

CONTENTS
- index.html: responsive website prototype with network selection, bundle selection, phone validation and order summary.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or another browser.

IMPORTANT BEFORE YOU ACCEPT REAL ORDERS
- The displayed prices are placeholders. Replace them with your actual approved prices.
- The WhatsApp button is not connected to a business number yet. Configure it before launch.
- This is a front-end prototype only. It does not collect payments, send data bundles, or store orders.
- To run a real data business, connect a trusted fulfilment provider/API, a secure payment provider, server-side order handling, and an admin dashboard. Never put payment secret keys in browser code.
- Add your business contact details, terms, privacy notice, refund policy and support process.
- Confirm your rights to resell bundles and use network branding.

CUSTOMISING PRICES
In index.html, find the buttons with class="bundle". Update each data-price and the displayed GHS amount. Keep the values consistent.
